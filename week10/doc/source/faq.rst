자주 묻는 질문 (FAQ)
====================

Q1. CFL 조건을 위반하면 어떻게 되나요?
----------------------------------------

수치 시뮬레이션이 **발산**\ 합니다. CFL 수가 1을 초과하면 각 격자점의 업데이트가
인접 점들의 실제 물리적 영향권을 넘어서게 되어, 오류가 지수적으로 증폭됩니다.

**확인 방법**: ``CFL = 1.1`` 로 설정하고 실행하면 몇 스텝 후 값이 무한대로 발산하는 것을 확인할 수 있습니다.

Q2. 전위는 :math:`1/r` 인데 전기장은 :math:`1/r^2` 인 이유는 무엇인가요?
---------------------------------------------------------------------------

전기장은 전위의 **기울기(gradient)** 이기 때문입니다:

.. math::

   E = -\frac{dV}{dr} = -\frac{d}{dr}\left(\frac{kQ}{r}\right) = \frac{kQ}{r^2}

미분하면 차수가 하나 올라갑니다.

Q3. 자기 단극(Magnetic Monopole)은 왜 존재하지 않나요?
-------------------------------------------------------

맥스웰 방정식의 두 번째 식:

.. math::

   \nabla \cdot \mathbf{B} = 0

이 식은 자기장선이 항상 **닫힌 루프**\ 를 이루며, 시작점이나 끝점이 없음을 의미합니다.
전기장의 :math:`\nabla \cdot \mathbf{E} = \rho/\varepsilon_0` 와 달리,
자기장에는 "자기 전하"에 해당하는 항이 없습니다.

일부 대통일 이론은 자기 단극의 존재를 예측하지만, 아직 실험적으로 발견되지 않았습니다.

Q4. 광속 :math:`c = 3 \times 10^8\ \mathrm{m/s}` 는 어디서 나오나요?
-----------------------------------------------------------------------

맥스웰 방정식으로부터 전자기파의 속도를 유도하면:

.. math::

   c = \frac{1}{\sqrt{\mu_0 \varepsilon_0}}
   = \frac{1}{\sqrt{4\pi \times 10^{-7} \times 8.85 \times 10^{-12}}}
   \approx 3 \times 10^8\ \mathrm{m/s}

맥스웰이 1865년에 이 계산을 통해 빛이 전자기파임을 예측했습니다.

Q5. FDTD와 FEM(유한 요소법)의 차이는 무엇인가요?
--------------------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 25 37 38

   * - 항목
     - FDTD
     - FEM
   * - 격자
     - 균일한 직교 격자
     - 임의 형태 격자 (삼각형 등)
   * - 적용 분야
     - 파동 전파 (시간 영역)
     - 구조 해석, 정적 문제
   * - 복잡한 형상
     - 계단 근사 필요
     - 곡면을 정확히 표현
   * - 계산 속도
     - 빠름 (단순한 격자)
     - 느림 (복잡한 행렬)
   * - 사용 예
     - 안테나, 광학 소자
     - 자동차, 구조물 해석

Q6. Python으로 전자기 시뮬레이션이 가능한가요?
----------------------------------------------

학습 목적과 중소 규모 문제에는 충분합니다.
대규모 3D 시뮬레이션은 C++/Fortran 기반 전문 소프트웨어를 사용합니다.
Python의 장점은 코드 가독성과 빠른 프로토타이핑입니다.

성능이 필요하면 ``numba`` (JIT 컴파일) 또는 ``cupy`` (GPU 가속)를 활용하세요.

Q7. 왜 격자점 근처에서 전기장이 발산하나요?
--------------------------------------------

점전하 모델에서 :math:`r \to 0` 이면 :math:`E \to \infty` 가 됩니다.
이는 수학적 이상화(idealisation)이며, 실제 물리에서는 유한 크기의 전하 분포를 사용합니다.

코드에서는 ``r = np.maximum(r, 1e-10)`` 으로 최소 거리를 설정하여
수치 오류를 방지합니다.

Q8. Gauss-Seidel 반복법이 항상 수렴하나요?
-------------------------------------------

라플라스 방정식(Dirichlet 경계 조건)에서는 **항상 수렴**\ 합니다.
이는 라플라시안 행렬이 대각 우세(diagonally dominant)이기 때문입니다.

수렴하지 않는 경우는:

- 경계 조건이 불완전하거나 모순될 때
- 수렴 기준 ``tol`` 이 컴퓨터 정밀도보다 낮게 설정될 때
