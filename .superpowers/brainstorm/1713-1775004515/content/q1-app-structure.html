Q1 · 앱 구조: 하나로 묶을까, 따로 만들까?

week4 에는 Lab 4개가 있습니다. PySide6 앱을 어떻게 구성할지 선택해 주세요.

A

통합 단일 앱 (탭/사이드바)

하나의 메인 윈도우 안에 Lab 1~4를 탭 또는 사이드바로 전환.

장점: 설치·실행 파일 1개, 랩 간 공통 UI 공유, 학습자가 한 화면에서 모두 비교 가능.

단점: 초기 로딩 시 TensorFlow 모델 전체 로드, 구조가 약간 복잡.

B

랩별 독립 실행 앱 (4개 파일)

week3처럼 각 Lab을 독립 폴더로 관리. python main.py 로 각각 실행.

장점: 구조 단순, 각 Lab에 집중, week3 패턴 그대로 유지.

단점: 4번 실행해야 함, 공통 코드 중복.
