# PRD — 퍼셉트론 학습 도구 (Perceptron Visualizer)

> **버전:** 1.0.0  
> **작성일:** 2025년 기준  
> **대상 독자:** 개발자, 강의 조교, 학습자 본인  

---

## 1. 제품 개요

### 1.1 한 줄 요약

> 퍼셉트론의 이론·학습·조작을 **하나의 데스크톱 앱**에서 체험할 수 있는 개인 학습 도구

### 1.2 배경 및 문제 정의

대학 물리·공학 과정에서 신경망을 처음 접하는 학습자는 다음과 같은 어려움을 겪는다.

- 퍼셉트론의 수학 공식과 실제 동작이 **머릿속에서 연결되지 않음**
- AND/OR은 학습되는데 XOR이 실패하는 이유를 **직관적으로 납득하기 어려움**
- 가중치·편향이 결정 경계에 미치는 영향을 **실시간으로 실험할 환경이 없음**
- 기존 Jupyter Notebook 기반 코드는 **인터랙션이 없어 수동적인 학습에 머무름**

### 1.3 목표

| 목표 | 세부 내용 |
|------|-----------|
| **이해** | 퍼셉트론의 개념·수식·학습 알고리즘을 구조화된 텍스트로 제공 |
| **관찰** | 에포크별 실시간 학습 애니메이션으로 결정 경계 변화 확인 |
| **탐색** | 가중치·편향 슬라이더로 결정 경계를 직접 조작 |
| **비교** | AND/OR/XOR 게이트를 전환하며 선형 분리 가능성 차이 체감 |

## 2. 사용자 정의

### 2.1 1차 사용자 (Primary)

| 속성 | 내용 |
|------|------|
| 역할 | 대학교 물리·공학·컴퓨터과학 전공 학부생 |
| 목적 | 신경망 기초 개념 개인 학습·복습 |
| 환경 | Windows/macOS 데스크톱, Python 환경 구성 가능 |
| 숙련도 | Python 기초 가능, 신경망은 처음 또는 초급 |

### 2.2 사용 시나리오

```
1. 앱 실행 → "이론 설명" 탭에서 퍼셉트론 개념 읽기
2. "학습 시뮬레이션" 탭 → AND 게이트, η=0.1, 100에포크 → 학습 시작
3. 결정 경계가 수렴하는 과정 관찰, 로그 확인
4. XOR 게이트로 전환 → 학습 실패 체험
5. "직접 조작" 탭 → 슬라이더로 w₁/w₂/b 조작 → 직선이 이동하는 것 확인
6. AND 프리셋 버튼 → 완벽한 AND 분리 상태 확인
```

## 3. 기능 요구사항

### 3.1 탭 1 — 이론 설명 (Theory)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-T-01 | 퍼셉트론 개념 HTML 렌더링 (스크롤 가능) | Must |
| F-T-02 | 수식 (순입력, 계단 함수, 학습 규칙) 표시 | Must |
| F-T-03 | 논리 게이트 진리표 | Must |
| F-T-04 | 선형 분리 가능성 설명 (AND/OR ✓, XOR ✗) | Must |
| F-T-05 | 수렴 정리 설명 | Should |
| F-T-06 | 학습 가이드 링크 (시뮬레이션 탭 안내) | Could |

### 3.2 탭 2 — 학습 시뮬레이션 (Simulation)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-S-01 | AND / OR / XOR 게이트 라디오 선택 | Must |
| F-S-02 | 학습률(η) 슬라이더 (0.01 ~ 1.00) | Must |
| F-S-03 | 에포크 수 스핀박스 (10 ~ 2000) | Must |
| F-S-04 | 애니메이션 속도 슬라이더 (매우 느림 ~ 최고속) | Must |
| F-S-05 | 학습 시작 / 일시 정지 / 재개 버튼 | Must |
| F-S-06 | 초기화 버튼 (가중치 랜덤 재설정) | Must |
| F-S-07 | 결정 경계 실시간 업데이트 (Matplotlib embed) | Must |
| F-S-08 | 정확도 변화 그래프 (에포크 vs 정확도) | Must |
| F-S-09 | 학습 로그 테이블 (에포크, w₁, w₂, b, 정확도) | Must |
| F-S-10 | 수렴 완료 / XOR 실패 메시지 자동 표시 | Must |
| F-S-11 | 게이트 변경 시 자동 초기화 | Should |
| F-S-12 | 100% 정확도 달성 시 조기 종료 (XOR 제외) | Should |

### 3.3 탭 3 — 직접 조작 (Manual Control)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-M-01 | w₁ 슬라이더 (−3.0 ~ +3.0, 0.01 단위) | Must |
| F-M-02 | w₂ 슬라이더 (−3.0 ~ +3.0, 0.01 단위) | Must |
| F-M-03 | b 슬라이더 (−3.0 ~ +3.0, 0.01 단위) | Must |
| F-M-04 | 결정 경계 실시간 시각화 (슬라이더 조작 즉시) | Must |
| F-M-05 | 순입력(z) 히트맵 subplot | Must |
| F-M-06 | 현재 수식 및 결정 경계 수식 표시 | Must |
| F-M-07 | 4개 입력에 대한 예측 결과 테이블 (z값 포함) | Must |
| F-M-08 | AND/OR/XOR 진리표 비교 | Should |
| F-M-09 | AND · OR · 초기화 빠른 프리셋 버튼 | Should |

## 7. 성공 지표

- AND/OR 게이트에서 100% 정확도 도달 확인 가능
- XOR 실패 메시지가 명확히 표시됨
- 슬라이더 조작 후 즉시 결정 경계 갱신 (체감 지연 없음)
- 이론 탭만으로 퍼셉트론 공식·학습 규칙 이해 가능
