# PRD — 활성화 함수 학습 도구 (Activation Functions Visualizer)

> **버전:** 1.0.0
> **작성일:** 2026-03-25
> **대상 독자:** 개발자, 강의 조교, 학습자 본인

---

## 1. 제품 개요

### 1.1 한 줄 요약

> 활성화 함수의 수식·형태·미분을 **하나의 데스크톱 앱**에서 인터랙티브하게 탐색하는 개인 학습 도구

### 1.2 배경 및 문제 정의

신경망을 처음 배우는 학습자는 다음과 같은 어려움을 겪는다.

- Sigmoid·Tanh·ReLU·Leaky ReLU의 **수식과 그래프 형태가 직관적으로 연결되지 않음**
- 미분(기울기)이 역전파에서 왜 중요한지 **시각적 증거 없이 이해하기 어려움**
- Vanishing Gradient·Dying ReLU 문제를 **정적 그림만으로는 체감하기 어려움**
- 여러 함수를 **동시에 비교할 인터랙티브 환경이 없음**

### 1.3 목표

| 목표 | 세부 내용 |
|------|-----------|
| **이해** | 각 활성화 함수의 개념·수식·특성을 구조화된 이론 탭에서 제공 |
| **탐색** | x값 슬라이더로 특정 입력에서 f(x)·f'(x)를 실시간 확인 |
| **비교** | 여러 함수를 동시에 겹쳐 보며 형태·기울기 차이 체감 |
| **직관** | 기울기 소실(Vanishing Gradient) 구간을 시각적으로 체감 |

## 2. 사용자 정의

### 2.1 1차 사용자 (Primary)

| 속성 | 내용 |
|------|------|
| 역할 | 대학교 물리·공학·컴퓨터과학 전공 학부생 |
| 목적 | 신경망 활성화 함수 개인 학습·복습 |
| 환경 | Windows/macOS 데스크톱, Python 환경 구성 가능 |
| 숙련도 | Python 기초 가능, 신경망은 처음 또는 초급 |

### 2.2 사용 시나리오

```
1. 앱 실행 → "이론 설명" 탭에서 활성화 함수 개념·수식 읽기
2. "함수 탐색" 탭 → Sigmoid 선택, x 슬라이더 이동 → f(x)와 f'(x) 실시간 확인
3. x → ±∞ 이동 → 기울기가 0에 수렴하는 Vanishing Gradient 체감
4. ReLU 선택 → x < 0에서 f'(x) = 0인 Dying ReLU 구간 확인
5. "비교" 탭 → 4개 함수 동시 표시 → 형태·기울기 차이 직접 비교
```

## 3. 기능 요구사항

### 3.1 탭 1 — 이론 설명 (Theory)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-T-01 | 활성화 함수 개요 HTML 렌더링 (스크롤 가능) | Must |
| F-T-02 | Sigmoid·Tanh·ReLU·Leaky ReLU 수식 및 범위 표시 | Must |
| F-T-03 | 각 함수의 장단점·사용 용도 표 | Must |
| F-T-04 | Vanishing Gradient·Dying ReLU 문제 설명 | Must |
| F-T-05 | 권장 사용 가이드 (은닉층·출력층별) | Should |

### 3.2 탭 2 — 함수 탐색 (Explorer)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-E-01 | Sigmoid / Tanh / ReLU / Leaky ReLU 라디오 선택 | Must |
| F-E-02 | x 입력 슬라이더 (−6.0 ~ +6.0, 0.05 단위) | Must |
| F-E-03 | 함수값 f(x) 실시간 표시 | Must |
| F-E-04 | 미분값 f'(x) 실시간 표시 | Must |
| F-E-05 | 현재 x 위치에 수직선 + 점 표시 (Matplotlib) | Must |
| F-E-06 | 접선(기울기) 표시 토글 | Must |
| F-E-07 | Leaky ReLU alpha 슬라이더 (0.01 ~ 0.5) | Should |
| F-E-08 | 현재 수식 패널 표시 (선택된 함수에 맞게 갱신) | Should |

### 3.3 탭 3 — 비교 (Comparison)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-C-01 | 함수별 체크박스 (개별 토글) | Must |
| F-C-02 | 함수 비교 / 미분 비교 모드 토글 | Must |
| F-C-03 | X 범위 슬라이더 (1 ~ 10) | Must |
| F-C-04 | 선택된 함수 오버레이 플롯 | Must |
| F-C-05 | 범례·색상 자동 구분 | Must |
| F-C-06 | 기울기 최댓값 표시 (Vanishing 정도 비교) | Should |
