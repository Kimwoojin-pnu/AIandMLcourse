# PRD — 범용 근사 학습 도구 (Universal Approximation Visualizer)

> **버전:** 1.0.0
> **작성일:** 2026-03-25
> **대상 독자:** 개발자, 강의 조교, 학습자 본인

---

## 1. 제품 개요

### 1.1 한 줄 요약

> 뉴런 수에 따라 복잡한 함수 근사 품질이 어떻게 달라지는지 **실시간 학습 애니메이션**으로 체험하는 개인 학습 도구

### 1.2 배경 및 문제 정의

- 범용 근사 정리(UAT)는 이론적으로 알지만 **뉴런이 실제로 함수를 어떻게 근사하는지 체감 어려움**
- 뉴런 3개와 50개의 근사 품질 차이를 **나란히 비교하며 관찰할 환경이 없음**
- 다양한 목표 함수(Sine/Step/Complex)에서 **같은 네트워크가 어떻게 다르게 학습하는지 비교 불가**

### 1.3 목표

| 목표 | 세부 내용 |
|------|-----------|
| **이해** | 범용 근사 정리 개념·수식을 이론 탭에서 제공 |
| **관찰** | 뉴런 수 슬라이더로 근사 품질 실시간 확인 |
| **비교** | 3·10·50 뉴런 3개를 동시에 학습·비교 |
| **탐색** | Sine/Step/Complex 함수 전환하며 난이도 비교 |

---

## 2. 사용자 정의

### 2.1 사용 시나리오

```
1. 앱 실행 → "이론 설명" 탭에서 범용 근사 정리 읽기
2. "함수 근사" 탭 → Sine Wave 선택, 3개 뉴런 → 학습 시작 → 거친 근사 확인
3. 뉴런 수를 50으로 늘리고 → 재학습 → 거의 완벽한 근사 확인
4. Step 함수로 전환 → 불연속 함수 근사의 어려움 체감
5. "뉴런 비교" 탭 → 3/10/50 뉴런 동시 비교 → MSE 차이 확인
```

## 3. 기능 요구사항

### 3.1 탭 1 — 이론 설명 (Theory)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-T-01 | 범용 근사 정리 개념·수식 HTML | Must |
| F-T-02 | Cybenko 1989 정리 공식 표시 | Must |
| F-T-03 | 깊이 vs 폭(width) 트레이드오프 설명 | Should |

### 3.2 탭 2 — 함수 근사 (Approximation)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-A-01 | 목표 함수 라디오 (Sine / Step / Complex) | Must |
| F-A-02 | 뉴런 수 슬라이더 (2 ~ 100) | Must |
| F-A-03 | 학습률 슬라이더 (0.001 ~ 0.1) | Must |
| F-A-04 | 에포크 스핀박스 (500 ~ 20000) | Must |
| F-A-05 | 학습 시작 / 초기화 버튼 | Must |
| F-A-06 | 실제 함수 vs NN 근사 오버레이 플롯 | Must |
| F-A-07 | MSE 실시간 표시 | Must |
| F-A-08 | 애니메이션 속도 슬라이더 (실시간 학습) | Must |
| F-A-09 | 학습 진행 Loss 곡선 서브플롯 | Should |

### 3.3 탭 3 — 뉴런 수 비교 (Comparison)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-C-01 | 목표 함수 라디오 선택 | Must |
| F-C-02 | 3개 뉴런 / 10개 뉴런 / 50개 뉴런 동시 학습 | Must |
| F-C-03 | 3-subplot 병렬 비교 플롯 | Must |
| F-C-04 | 각 subplot에 MSE 표시 | Must |
| F-C-05 | "모두 학습" 버튼 → 3개 모델 순차 학습 | Must |
