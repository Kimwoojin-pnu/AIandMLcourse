# PRD — 순전파 학습 도구 (Forward Propagation Visualizer)

> **버전:** 1.0.0
> **작성일:** 2026-03-25
> **대상 독자:** 개발자, 강의 조교, 학습자 본인

---

## 1. 제품 개요

### 1.1 한 줄 요약

> 2-3-1 신경망의 순전파를 **입력값 조작과 단계별 시각화**로 직접 체험하는 개인 학습 도구

### 1.2 배경 및 문제 정의

- 행렬 연산 z = X@W + b가 **뉴런 다이어그램과 연결되지 않음**
- 은닉층 뉴런 값이 입력에 따라 어떻게 변하는지 **동적으로 확인할 수 없음**
- 활성화 함수 적용 전후 값 차이를 **직관적으로 비교하기 어려움**
- 가중치 행렬이 실제로 어떤 변환을 수행하는지 **시각적 증거가 없음**

### 1.3 목표

| 목표 | 세부 내용 |
|------|-----------|
| **이해** | 순전파의 개념·수식을 구조화된 이론 탭에서 제공 |
| **관찰** | x1·x2 입력 슬라이더 조작으로 각 뉴런 활성화 실시간 확인 |
| **시각화** | 뉴런 다이어그램에 활성화 강도 색상 매핑 |
| **분석** | 가중치 행렬을 히트맵으로 시각화 |

---

## 2. 사용자 정의

### 2.1 사용 시나리오

```
1. 앱 실행 → "이론 설명" 탭에서 순전파 개념·수식 읽기
2. "순전파 탐색" 탭 → x1=0.5, x2=0.8 설정 → 각 뉴런 활성화값 확인
3. x1 슬라이더를 −2 → +2 이동 → 뉴런 색상 변화 관찰
4. "가중치 무작위" 버튼 → 다른 가중치에서의 결과 비교
5. "행렬 시각화" 탭 → W1·W2 히트맵으로 가중치 구조 파악
```

## 3. 기능 요구사항

### 3.1 탭 1 — 이론 설명 (Theory)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-T-01 | 순전파 개념 HTML 렌더링 | Must |
| F-T-02 | z₁ = X@W₁+b₁, a₁ = ReLU(z₁) 수식 | Must |
| F-T-03 | z₂ = a₁@W₂+b₂, a₂ = Sigmoid(z₂) 수식 | Must |
| F-T-04 | 2-3-1 네트워크 구조 설명 | Must |

### 3.2 탭 2 — 순전파 탐색 (Explorer)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-E-01 | x1 슬라이더 (−3.0 ~ +3.0) | Must |
| F-E-02 | x2 슬라이더 (−3.0 ~ +3.0) | Must |
| F-E-03 | 뉴런 다이어그램 (입력·은닉·출력층) | Must |
| F-E-04 | 뉴런 색상 = 활성화 강도 (파랑↔빨강 컬러맵) | Must |
| F-E-05 | 각 뉴런에 활성화값 텍스트 표시 | Must |
| F-E-06 | z1 (before ReLU) vs a1 (after ReLU) 막대 비교 | Must |
| F-E-07 | 최종 출력 a₂ 값 강조 표시 | Must |
| F-E-08 | 가중치 무작위 초기화 버튼 | Must |
| F-E-09 | Seed 고정 체크박스 (재현성) | Should |

### 3.3 탭 3 — 행렬 시각화 (Matrix View)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-M-01 | W1 (2×3) 히트맵 | Must |
| F-M-02 | W2 (3×1) 히트맵 | Must |
| F-M-03 | z1·a1 막대 차트 (비교) | Must |
| F-M-04 | z2·a2 값 표시 | Must |
| F-M-05 | 가중치 값 셀 내 텍스트 표시 | Should |
