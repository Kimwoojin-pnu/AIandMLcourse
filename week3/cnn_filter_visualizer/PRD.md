## 1. 제품 개요

### 1-1. 배경 및 목적

MIT 6.S191 Lecture 3 강의를 통해 합성곱 신경망(CNN)의 핵심 연산인 합성곱(Convolution)의 작동 원리를 학습하였다. 강의 중 브라우저 위젯으로 필터 슬라이딩을 시각화하는 인터랙티브 도구를 경험하였으며, 이를 로컬 Python 데스크탑 애플리케이션으로 구현하여 언제든지 VS Code 환경에서 실행할 수 있게 하고자 한다.

v1.0의 8×8 픽셀 그리드는 실제 이미지의 패턴을 식별할 수 없을 만큼 저해상도였다. v2.0에서는 **128×128 해상도**를 채택하여 실제 이미지(사진, 그래픽)를 그대로 불러와 필터 효과를 직관적으로 확인할 수 있게 한다.

### 1-2. 제품 비전

> 학습자가 실제 이미지를 128×128로 불러와 합성곱 필터가 슬라이딩하는 전 과정을 시각적으로 확인함으로써, CNN의 Feature Map 생성 원리를 직관적으로 이해할 수 있는 데스크탑 학습 도구.

### 1-3. 대상 사용자

- **주 사용자**: 머신러닝/딥러닝을 처음 배우는 대학생 및 입문자
- **사용 맥락**: 강의 복습, 개인 학습, 과제 발표 시연

## 2. 기능 요구사항

### 2-1. 사용자 스토리

| ID | 사용자 스토리 | 수락 기준 |
|----|--------------|----------|
| US-01 | 사용자로서, 이미지 파일(PNG/JPG)을 불러와 자동으로 그레이스케일 128×128로 리사이즈 후 시각화하고 싶다. | 파일 다이얼로그로 선택, 리사이즈 후 캔버스에 반영 |
| US-02 | 사용자로서, 기본 제공 패턴(수직 경계 128×128)으로 즉시 시작할 수 있다. | 앱 시작 시 기본 패턴 자동 표시 |
| US-03 | 사용자로서, 3가지 사전 정의된 필터(Sharpen, Edge Detect, Sobel X) 중 하나를 선택하고 싶다. | 라디오 버튼으로 선택, 커널 값 즉시 표시 |
| US-04 | 사용자로서, Step 버튼을 눌러 필터가 한 칸씩 슬라이딩하는 과정을 볼 수 있다. | 한 번 클릭 = 1위치 이동, 입력 슬라이딩 창 하이라이트 + 계산식 표시 |
| US-05 | 사용자로서, Auto 버튼으로 전체 슬라이딩을 자동 재생할 수 있다. | 속도 조절 슬라이더 연동, 일시정지/재개 가능, 배치 처리로 부드러운 재생 |
| US-06 | 사용자로서, 현재 위치의 입력 패치 × 필터 계산 과정을 숫자로 확인할 수 있다. | 3×3 패치 × 3×3 필터 = 원소별 곱 → 합계 → 출력값 표시 |
| US-07 | 사용자로서, Reset 버튼으로 처음 상태로 돌아갈 수 있다. | Feature Map 초기화, 필터 선택 유지 |

### 2-2. 필터 사양

| 필터 이름 | 커널 (3×3) | 출력 처리 | 효과 |
|-----------|-----------|----------|------|
| Sharpen | `0,-1,0 / -1,5,-1 / 0,-1,0` | clamp(0,255) | 에지 강조 |
| Edge Detect | `0,1,0 / 1,-4,1 / 0,1,0` | abs → clamp(0,255) | 전방향 에지 |
| Sobel X | `-1,0,1 / -2,0,2 / -1,0,1` | abs → clamp(0,255) | 수직 에지 |

### 2-3. 이미지 입력 사양

| 항목 | 사양 |
|------|------|
| 직접 픽셀 편집 | 미지원 (128×128 = 16,384셀은 UI 편집 불가) |
| 기본 패턴 | 좌절반=200, 우절반=30 수직 경계 128×128 |
| 파일 업로드 형식 | PNG, JPG, JPEG, BMP |
| 파일 업로드 처리 | 그레이스케일 변환 → 128×128 리사이즈 (PIL LANCZOS) |
| 캔버스 표시 크기 | 256×256 px (2배 업스케일, NEAREST) |

## 4. UI 레이아웃 요구사항

전체 창은 3개의 수평 패널로 구성된다.

| 패널 | 포함 요소 |
|------|----------|
| 왼쪽 | 256×256 Canvas (128×128 이미지 표시) + 파일 업로드 버튼. 현재 슬라이딩 창(3×3)을 빨간 테두리 사각형으로 오버레이 |
| 중앙 | 필터 선택 UI + 3×3 커널 값 표시 + 계산식 (패치 × 필터 = 원소별 곱 → 합계 → 출력값) + Step/Auto/Reset 버튼 + 속도 슬라이더 + 진행 표시 |
| 오른쪽 | 252×252 Canvas (126×126 Feature Map 실시간 표시). 완료 픽셀은 그레이스케일, 미완료는 회색 |

---

## 5. 제약 및 가정

- 입력 이미지 크기는 128×128 고정 (Stride=1, Valid Convolution → 출력 126×126)
- 필터 크기는 3×3 고정
- 다중 채널(컬러)은 v2.0 범위 외 (그레이스케일만 지원)
- GPU 연산 불필요, CPU만 사용
- 직접 픽셀 편집(Entry 그리드) 미지원 — 파일 업로드 또는 기본 패턴 사용
- 별도 설치 패키지는 Pillow 1개로 제한

---

## 6. 성공 지표

- `python main.py` 실행 후 창이 3초 이내 열린다
- PNG/JPG 파일 업로드 → 그레이스케일 128×128 변환 → 슬라이딩 정상 동작
- Auto 재생 speed=10에서 전체 15,876 스텝이 약 8~15초 내 완료
- Sobel X 필터 적용 시 Feature Map 캔버스에 수직 에지가 시각적으로 나타난다
- Reset 후 재시작 오류 없음
