# PRD — MLP 학습 도구 (MLP Visualizer)

> **버전:** 1.0.0
> **작성일:** 2026-03-25
> **대상 독자:** 개발자, 강의 조교, 학습자 본인

---

## 1. 제품 개요

### 1.1 한 줄 요약

> XOR 문제를 Numpy MLP로 해결하는 과정을 **역전파 시각화와 함께 체험**하는 개인 학습 도구

### 1.2 배경 및 문제 정의

- 단층 퍼셉트론이 XOR을 못 푸는 이유를 알지만 **MLP가 어떻게 해결하는지 직관이 없음**
- 역전파(Backpropagation)의 수식은 알지만 **실제 경사가 어떻게 흐르는지 볼 수 없음**
- Loss 감소 곡선을 **에포크별 실시간으로 보며 학습 진행을 체감하기 어려움**
- 은닉층 크기·학습률·에포크 수 변경이 **학습 결과에 미치는 영향 비교가 어려움**

### 1.3 목표

| 목표 | 세부 내용 |
|------|-----------|
| **이해** | MLP 구조·역전파 수식을 이론 탭에서 제공 |
| **관찰** | XOR 결정 경계와 Loss 곡선 실시간 애니메이션 |
| **탐색** | 하이퍼파라미터 조작 → 학습 결과 즉시 비교 |
| **분석** | W1·W2 경사 크기를 히트맵으로 시각화 |

---

## 2. 사용자 정의

### 2.1 사용 시나리오

```
1. 앱 실행 → "이론 설명" 탭에서 MLP·역전파 개념 읽기
2. "학습 시뮬레이션" 탭 → hidden=4, lr=0.5, 10000에포크 → 학습 시작
3. 결정 경계가 XOR을 분리하는 과정 관찰
4. hidden=2로 줄이고 재학습 → 성능 차이 비교
5. "경사 시각화" 탭 → 학습 중 W1·W2 경사 크기 변화 확인
```

## 3. 기능 요구사항

### 3.1 탭 1 — 이론 설명 (Theory)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-T-01 | MLP 구조 및 XOR 문제 설명 HTML | Must |
| F-T-02 | 역전파 핵심 공식 (연쇄 법칙) | Must |
| F-T-03 | Xavier 초기화 설명 | Should |

### 3.2 탭 2 — 학습 시뮬레이션 (Simulation)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-S-01 | 은닉 뉴런 수 스핀박스 (2 ~ 16) | Must |
| F-S-02 | 학습률 슬라이더 (0.01 ~ 2.0) | Must |
| F-S-03 | 배치 에포크 스핀박스 (100 ~ 50000) | Must |
| F-S-04 | 애니메이션 속도 슬라이더 | Must |
| F-S-05 | 학습 시작 / 일시정지 / 재개 버튼 | Must |
| F-S-06 | 초기화 버튼 (가중치 재설정) | Must |
| F-S-07 | XOR 결정 경계 실시간 업데이트 | Must |
| F-S-08 | Loss 곡선 실시간 업데이트 (log scale) | Must |
| F-S-09 | 학습 로그 테이블 (에포크, Loss, 정확도) | Must |
| F-S-10 | 100% 정확도 달성 시 완료 메시지 | Must |

### 3.3 탭 3 — 경사 시각화 (Gradient View)

| ID | 기능 | 우선순위 |
|----|------|----------|
| F-G-01 | dW1 경사 히트맵 (학습 중 실시간) | Must |
| F-G-02 | dW2 경사 히트맵 (학습 중 실시간) | Must |
| F-G-03 | 경사 크기 막대 차트 (레이어별) | Must |
| F-G-04 | 은닉층 활성화 히트맵 (4개 샘플 × n_hidden) | Should |
