### Lab 1 — Euler vs RK4 (`01euler_rk4.py`)

**초기 조건**: x(0)=1, v(0)=0, ω=2π rad/s, dt=0.1 s, t_max=10 s

| 방법 | 에너지 오차 (t=10 s) | 감쇠 진자 최종 각도 |
|------|---------------------|-------------------|
| Euler | 3.94 × 10¹⁴ % (발산) | −17588.69° |
| RK4 | −7.88% (수치 감쇠) | −18.93° |

**물리적 해석**

- **Euler 발산**: SHO에서 Euler 증폭인자 `|1 + iωdt| = 1.181 > 1` — 허수 고유값 시스템에서 이론적으로 반드시 발산.
- **RK4 −7.88% 감쇠**: `ωdt = 0.628`에서 RK4 증폭인자 `|R| = 0.9996 < 1`.  
  100스텝 후 에너지 이론 감쇠: **−7.81%** → 실제 −7.88%와 0.07% 오차 내 일치.  
  이는 에너지 소산이 아니라 RK4 자체의 수치 감쇠(numerical damping) 현상.

### Lab 3 — 혼돈 이중 진자 (`03chaotic_pendulum.py`)

#### 발견된 버그: 에너지 오차 계산 오류

**문제**: 초기 조건 θ₁ = θ₂ = 90°, ω₁ = ω₂ = 0 으로 설정되어 있어

```
E₀ = T + V = 0 + (m₁g·y₁ + m₂g·y₂) = 0 + 0 = 0 J
```

`ΔE/|E₀|` 계산 시 분모가 0이 되어 수치 폭발.

**수정 전 출력**:
```
진자 A: ΔE/E0 = 112274529124188.3281%  ← 분모=0, 무의미한 수치
진자 B: ΔE/E0 = 1058.6491%             ← E0≈1.7e-4 J (너무 작음)
```

**수정 내용** (`03chaotic_pendulum.py`, 3줄 추가/변경):

```python
# 수정 전
E_scale = (m1 + m2) * g * (L1 + L2)

def energy_error_str(E):
    dE = E.max() - E.min()
    E0 = abs(E[0])
    if E0 > 1e-6:                       # 임계값이 너무 낮아 진자 B를 잡지 못함
        return f"dE/E0 = {dE/E0*100:.4f}%"
    else:
        return f"dE = {dE:.6f} J  dE/E_scale = {dE/E_scale*100:.6f}%"

# 수정 후
E_scale = (m1 + m2) * g * (L1 + L2)    # ≈ 39.24 J (시스템 최대 위치에너지)

def energy_error_str(E):
    dE = E.max() - E.min()
    E0 = abs(E[0])
    if E0 > E_scale * 0.01:             # E_scale의 1% 이상이면 상대 오차 사용
        return f"dE/E0 = {dE/E0*100:.4f}%"
    else:
        return f"dE = {dE:.6f} J (E0<<E_scale)  dE/E_scale = {dE/E_scale*100:.6f}%"
```

**수정 후 출력**:
```
진자 A: dE = 0.002023 J  dE/E_scale = 0.005156%   ← 30초 혼돈 시뮬레이션, 우수
진자 B: dE = 0.001813 J  dE/E_scale = 0.004619%   ← 정상
```

#### 리아푸노프 지수 검증

```
λ = 0.556 s⁻¹  (문헌 범위: 0.2 ~ 0.7 s⁻¹, 초기 조건 의존)

예측 발산 시각 = ln(0.1 m / ε) / λ
              = ln(0.1 / 1.745×10⁻⁵) / 0.556
              = 15.56 s

시뮬레이션 관측 발산 시각: 15.59 s  →  오차 0.2%
```

### Lab 4 — 라그랑지안 / 해밀토니안 (`04lagrangian_hamiltonian.py`)

초기 조건: θ(0) = 60°, ω(0) = 0

| 검증 항목 | 결과 |
|----------|------|
| Newton ↔ Lagrange 최대 차이 | < 10⁻¹⁰ rad |
| Newton ↔ Hamilton 최대 차이 | < 10⁻¹⁰ rad |
| 에너지 보존 오차 | < 0.000001% |

**이론값과 교차 검증**

```
초기 에너지 E₀ = −mgL·cos(60°) = −4.9050 J
최대 속도 (θ=0): v_max = √(2(E₀ + mgL)) = √(2·4.905) = 3.132 m/s
비선형 보정 주기: T = 2π√(L/g)·(1 + θ₀²/16) = 2.006 × 1.069 = 2.144 s
```

`ωdt = √(9.81) × 0.01 = 0.031` — 매우 작아 RK4 정확도 충분.
